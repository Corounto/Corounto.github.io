About

A structure inspired by strong academic lab sites

The Stanford SVL homepage works because it is easy to scan: visitors quickly understand who the lab is, what it works on, which projects matter most, and how to connect with the team. This template follows the same logic, while staying simple enough to deploy on github.io without any build step.

The content below is only sample text. You can keep this layout and swap in your own lab mission, members, project images, publications, and recruiting information. Everything is plain HTML and CSS, so it is easy to edit.
